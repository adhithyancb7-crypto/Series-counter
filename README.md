# 📺 Free Movies Details

A modern web-based **TV Series discovery and management platform** designed to help users discover TV series, search for series, explore series information, manage their watchlist, track watched series, create personal lists, and manage reviews and activity.

## 🚀 Features

### 📺 TV Series Discovery

* Browse TV series
* Search for TV series
* Live search suggestions
* View series information
* Explore series ratings and details
* Easy-to-use series discovery interface

### 🔎 Series Search

* Search TV series by title
* Live search suggestions while typing
* Quickly find the series you are looking for
* Simple and user-friendly search interface

### 👤 User Features

* User registration
* User login
* User profile
* Edit profile
* User activity
* Members section
* User reviews

### ❤️ Watchlist & Watched

* Add series to watchlist
* View saved series
* Mark series as watched
* View watched series
* Track series-watching activity

### 📝 Reviews & Likes

* Write reviews for TV series
* View series reviews
* View user reviews
* Like series
* Manage personal activity

### 📋 Series Lists

* Create personal series lists
* View saved lists
* Manage custom series collections
* My Lists section
* List view

### 📖 Series Diary

* Keep track of watched series
* Maintain a personal series diary
* View series-watching history
* Organize viewing activity

### 🏷️ Tags & Network

* Series tags
* User network
* Members
* Activity pages

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the Project

```bash
cd FreeMoviesDetails
```

### 3. Install Dependencies

This project is a frontend web application and does not require a package installation if all required files are already included.

Open the project folder in **Visual Studio Code**.

### 4. Run the Project

You can open `index.html` directly in a browser.

For a better development experience, use **Live Server** in Visual Studio Code.

## 🔐 Environment Variables

The project may require an API key for retrieving TV series information.

For security, sensitive API keys should not be stored directly in the public repository.

Example:

```env
OMDB_API_KEY=your_api_key_here
```

### Important

* Never upload your real API key to GitHub.
* Keep private credentials outside the public repository.
* Use `.gitignore` to prevent sensitive files from being committed.
* The repository includes an example configuration file for reference.
